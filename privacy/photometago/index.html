Privacy Policy - PhotoMetaGo

Ultimo aggiornamento: 22 settembre 2026

Sviluppatore: Paolo Savio Videomaker e Fotografo

Contatto privacy: info@paolosavio.eu

1. Scopo dell'app

PhotoMetaGo è un'app per fotografi che consente di ricevere immagini da fotocamere compatibili tramite FTP, applicare metadati IPTC/XMP, gestire preset metadata e inviare fotografie verso destinazioni scelte dall'utente, incluse Google Drive e connessioni FTP/FTPS/SFTP.

2. Dati elaborati sul dispositivo

L'app può accedere, su scelta dell'utente, a fotografie JPEG, file preset JSON/XMP, metadati fotografici e configurazioni di trasferimento. Questi dati vengono normalmente elaborati localmente sul dispositivo per svolgere le funzioni richieste.

PhotoMetaGo non utilizza, nella versione attuale, SDK pubblicitari, sistemi di analytics o servizi di crash reporting gestiti dallo sviluppatore.

3. Trasferimento di fotografie

Quando l'utente usa la funzione DELIVER, PhotoMetaGo trasferisce le fotografie selezionate verso una destinazione configurata dall'utente. Il trasferimento avviene solo a seguito di un'azione dell'utente.

  • Google Drive: il trasferimento avviene tramite le API ufficiali di Google Drive e l'autorizzazione OAuth dell'utente.
  • FTPS/SFTP: i dati vengono trasferiti mediante protocolli cifrati.
  • FTP: il protocollo FTP tradizionale non cifra il contenuto o le credenziali durante il trasporto. L'utente dovrebbe utilizzarlo solo su reti e server considerati affidabili. Per trasferimenti su Internet sono raccomandati FTPS, SFTP o Google Drive.

Lo sviluppatore di PhotoMetaGo non riceve copie delle fotografie trasferite e non gestisce un server PhotoMetaGo per l'archiviazione delle immagini.

4. Google Drive e dati Google

La connessione a Google Drive è facoltativa. PhotoMetaGo richiede l'ambito https://www.googleapis.com/auth/drive.file, utilizzato esclusivamente per creare, caricare e gestire i file utilizzati dall'app nell'account Drive autorizzato dall'utente.

I dati Google ottenuti tramite le API Google vengono utilizzati esclusivamente per fornire la funzione visibile di consegna delle fotografie su Google Drive. Non vengono venduti, utilizzati per pubblicità, profilazione o analisi di marketing.

L'uso delle informazioni ricevute dalle API Google è soggetto alla Google API Services User Data Policy, inclusi i requisiti di Limited Use.

5. Credenziali e configurazioni

Le configurazioni FTP/FTPS/SFTP, i token OAuth di Google Drive, i preset e le preferenze dell'app vengono memorizzati localmente nello spazio privato dell'app sul dispositivo. Lo sviluppatore non riceve queste informazioni.

La disconnessione da Google Drive rimuove dall'app i token di autorizzazione memorizzati localmente. La disinstallazione dell'app elimina i dati locali gestiti dall'app secondo il normale comportamento di Android.

6. Conservazione dei file

Le fotografie salvate localmente rimangono sul dispositivo o nella cartella scelta dall'utente finché l'utente non le elimina. Le fotografie caricate su Google Drive o su server FTP/FTPS/SFTP rimangono presso la destinazione scelta e sono soggette alle regole di conservazione e privacy del relativo fornitore o server.

7. Eliminazione dei dati

PhotoMetaGo non crea un account PhotoMetaGo sul server dello sviluppatore. Per eliminare i dati locali è possibile cancellare i dati dell'app o disinstallarla. Per revocare l'accesso a Google Drive è possibile usare la funzione di disconnessione nell'app e, se necessario, le impostazioni di sicurezza dell'Account Google. I file già caricati devono essere eliminati direttamente dalla destinazione scelta dall'utente.

8. Condivisione e vendita

PhotoMetaGo non vende dati personali. I trasferimenti verso Google Drive o server configurati dall'utente avvengono esclusivamente su richiesta dell'utente e per realizzare la funzione di consegna scelta.

9. Sicurezza

PhotoMetaGo limita l'accesso ai file selezionati dall'utente e utilizza protocolli cifrati quando disponibili. La sicurezza effettiva di una destinazione FTP/FTPS/SFTP dipende anche dalla configurazione del server e della rete utilizzata.

10. Modifiche a questa informativa

Questa Privacy Policy potrà essere aggiornata in caso di modifiche alle funzioni dell'app, ai servizi di terze parti o ai requisiti normativi e di Google Play. La data di aggiornamento sarà indicata all'inizio del documento.

11. Contatti

Per richieste relative alla privacy o all'app: info@paolosavio.eu.
